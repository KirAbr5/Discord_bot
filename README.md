# Discord Bot

A simple class-based Discord bot, created as a project while learning OOP.

# 🔧 Setup

・Clone the repository.

・Create the following files in the project root:

ㅤ・api_key.txt → place your Discord API key inside.

ㅤ・gemini_token.txt → place your Gemini API token inside.

・Run the bot. The database bot_database.db will be created automatically on first launch.

# 📜 Available Commands

All currently supported commands are listed in help_me.txt
.
