Вот доступные команды для всех 🌍:
・!hello - рад поздороваться с тобой
・!help_me - список доступных команд
・!answer <question> - вопрос нейросети
・!randoms <var1> <var2> ... <varn> - выбор 1 варианта из нескольких через пробел (рандомный)
・!fight <@user> - бой с пльзователем, узнаем кто сильней
・!balance - узнать свой виртуальный баланс
・!work - работать на виртуальной работе
・!leaders - лидеры по монетам всех пользователей бота

Только для админов 🚩:
・!ban <@user> <reason> - бан пользователя с сервера
・!ban_id <id_user> <reason> -  бан пользователя с сервера по id
・!unban <id_user> - разбан пользователя на сервере по id
・!kick <@user> <reason> - кик пользователя с сервера
・!kick_id <id_user> <reason> - кик пользователя с сервера по id
・!mute <@user> <time in minutes> <reason> - тайм-аут пользователя (время в минутах)
・!unmute <@user> - закончить тайм-аут пользователя
